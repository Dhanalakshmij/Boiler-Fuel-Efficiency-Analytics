# Boiler Fuel Efficiency Analytics

Goal: analyze this energy domain using real, permitted data.

1. Define domain-specific targets and units.
2. Collect real data and avoid temporal leakage.
3. Benchmark recent algorithms against seasonal and ML baselines.
4. Add ablations, repeated trials, uncertainty, and operational impact.
5. Document dataset license, limitations, and deployment assumptions.

The included scripts and data are generic illustrative starters, not publication-ready results.
